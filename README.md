-> No android studio
===

# &#x09;1. Abra a pasta raiz do projeto no Android Studio (File > Open), a mesma

# &#x20;  	 que contém o arquivo `pubspec.yaml`.



# &#x09;2. No painel de arquivos à esquerda, navegue até `lib/`.



# &#x09;3. Clique com o botão direito no arquivo do exercício desejado

# &#x20;  	 (por exemplo, `exercicio1.dart`) e selecione \*\*Run 'exercicio1.dart'\*\*.



# &#x09;4. No seletor de dispositivo, no topo da tela, escolha o emulador Android,

# &#x20;  	 um dispositivo físico conectado ou \*\*Chrome\*\* para rodar no navegador.



# &#x09;5. Para testar outro exercício, pare a execução atual (botão de stop) e

# &#x20;  	 repita o processo com o arquivo desejado.

# 

# &#x09;Alternativamente, também é possível rodar pelo terminal integrado do

# &#x09;Android Studio:

# 

# &#x09;flutter run -d chrome -t lib/exercicio1.dart

# &#x09;

# 

# &#x09;Basta trocar `exercicio1.dart` pelo nome do exercício que deseja executar.
